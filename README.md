## 概要

素の HTML / CSS のみで構成した 1 ページ構成の静的サイトです。ビルドツール・
フレームワーク・パッケージマネージャは使っていません（`script.js` も現状は空実装です）。

掲載しているセクション:

| セクション | 内容 |
| --- | --- |
| Profile | 所属・連絡先・研究テーマ（Text-to-3D Hand-Object Interaction） |
| Internships | 産業技術総合研究所（AIST）RA、NEC インターンシップ |
| Activities | ハッカソン受賞、SIGBIO 発表、松尾研究室 修了講座 |
| Qualifications | 統計検定準1級 |

ヘッダーからは外部サイト（Statistics / Papers / Games）へリンクしています。

## ファイル構成

```
.
├── index.html   # ページ本体（全セクションのマークアップ）
├── style.css    # スタイル一式（リセット / レイアウト / 各セクション）
├── script.js    # 現状は空（JavaScript 不要のページ）
└── file/        # 配布資料
    └── sigbio_後藤.pdf
```

## ローカルでの確認

`index.html` をブラウザで直接開くだけでも表示できます。相対パス（`file/` 以下の PDF など）を
本番と同じ条件で確認したい場合は、簡易サーバ経由が確実です。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 公開

`main` ブランチにプッシュすると GitHub Pages がそのまま配信します。ビルド手順はありません。

```bash
git add -A
git commit -m "update"
git push origin main
```

## 編集のポイント

- 業績・活動を追加する場合は、`index.html` の該当セクションに `.entry` ブロックを追加します
  （`.entry-meta` にバッジと年、`.entry-body` にタイトル・掲載先・リンク）。
- 資格は `.qual-list` の `<li>` に `.qual-year` と説明を並べます。
- PDF などの配布物は `file/` に置き、`index.html` から相対パスで参照します。
- `.gitignore` で `statistics/note/` を除外しています。
